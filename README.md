# 🎓 EduScheduleApp
### University Timetable Management System

**Developed by BH YASSER**

EduScheduleApp is a Java desktop application independently developed by **BH YASSER** to simplify university timetable management. It provides a centralized platform for managing academic schedules, teachers, students, groups, classrooms, and subjects through a user-friendly graphical interface.

The application includes dedicated spaces for administrators, teachers, and students, with role-based access and MySQL database integration.

## ✨ Features

### 🔐 Authentication
- User login and role-based access.
- Dedicated interfaces for administrators, teachers, and students.
- Logout functionality.

### 🛠️ Administrator
- Manage teachers and students.
- Manage student groups and classrooms.
- Create, update, and delete subjects.
- Schedule and manage class sessions.
- Organize academic timetables.

### 👨‍🏫 Teacher
- View personal teaching schedules.
- Consult assigned subjects and student groups.
- View classrooms, days, and session times.

### 🎓 Student
- View the timetable associated with their group.
- Consult subjects, teachers, classrooms, and session times.

### 🖥️ User Interface
- Java Swing graphical interface.
- Organized navigation and role-specific dashboards.
- Interface sizing and layout improvements.

## 🧰 Technologies

- **Java** — Application development
- **Java Swing** — Graphical user interface
- **MySQL** — Relational database

## ⚙️ Getting Started

### Prerequisites
- Java JDK
- MySQL Server
- Eclipse IDE or another compatible Java IDE
- MySQL JDBC driver

### Installation

1. Clone or download this repository.
2. Open the project in your Java IDE.
3. Create the MySQL database using the SQL script included in the project.
4. Configure the database connection according to your local MySQL settings.
5. Ensure the JDBC driver is available in the project classpath.
6. Run the application's main Java class.

**Note:** The database name, SQL script path, and main class should match the actual project files. Check the database configuration before running the application.
